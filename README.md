# Venti releases

Native builds of Venti for macOS, Linux and Windows, plus the install scripts.

Install:

```sh
curl -fsSL https://venti.chillicream.cloud/install.sh | bash
```

```powershell
irm https://venti.chillicream.cloud/install.ps1 | iex
```

Each release carries the archives, a SHA256SUMS file and the scripts.
